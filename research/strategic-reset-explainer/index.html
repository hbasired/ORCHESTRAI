1. Why this reset happened

The operator requested an irregular system check: find loopholes and fix them, research whether the finished product will actually be adopted (and by whom, against whom, for what money), create a new PRD, add a product-manager discipline, and define what gets built next — all honest, sourced, and without faking anything.

Three internal facts made the timing right:

  • CTO Checkpoint #1 had ruled "spec-deep, code-thin — freeze new spec, build ONE vertical slice before widening." Stage 6 was sitting as an empty TBD skeleton awaiting exactly this decision.
  • The PRD was a four-file chain (v2.0→v2.1→v2.2→v2.3) a reader had to merge mentally — and the hook protecting "frozen" PRDs only covered v1, so the freeze rule was unenforced where it mattered.
  • CLAUDE.md had gone stale twice (wrong baseline, wrong "next stage"), proving the docs needed an anti-staleness mechanism, not just a correction.

And three external facts (June 2026 research) made it urgent: fleet orchestration commoditized (InOrbit open-sourced OpenRobOps), Cisco bought Galileo (the agent-reliability category validated and vacated), and the EU AI Act got fixed dates (Annex III: 2 Dec 2027) — together re-anchoring the moat on trust stack × causal self-healing above commodity orchestration.

  • G-031 / G-001 (owed independent CTO pass + Stage 3 re-audit) — operator decision: now hard pre-requisites of Stage 6, run at stage open.

5. Stage 6 decision & roadmap deltas

Stage 6 = Vertical Slice v0 — predict → diagnose → intervene, closed-loop inside SimPy on the machine-failure scenario, with a measured A/B (downtime with the loop ON vs OFF) as the headline artifact. Rationale: CTO #1's explicit gate; the predict leg already exists twice (XGBoost PR-AUC 0.847, LSTM MAPE 21%); a third predictor before any diagnose/intervene would repeat the breadth-outruns-build failure. The slice needs no LLM (diagnose v0 is deterministic) — free-cost safe — and no safety wrapper (sim-only, no real actuators).

Roadmap deltas (no new stages): 4 = PdM and 5 = demand recorded as actually shipped (defect detection moved to Stage 9); 6.5 energy deferred until after the slice; 7 (PPO) and 8 (world model + causal twin) re-described as deepening the slice's intervene/diagnose legs behind the same interfaces; 11 = the production slice (durable runtime, HITL, repair dispatch, active diagnosis — gaps G-005/G-014/G-025/G-026 unchanged); 16 now explicitly integrates OpenRobOps/Open-RMF (new gap G-041). The CTO remediation map was reinterpreted via ADR (v0 at 6, production at 11), never edited.

6. New role: product-manager

The 12th persona (.claude/skills/product-manager/SKILL.md). Mission: own the product-market-fit evidence and the PRD chain — without expanding build scope (the CTO freeze verdict binds it explicitly). Key contracts: every number sourced or labeled; research-log append every session; PRD changes only as new version files; claims must match BUILT/PARTIAL/PLANNED status; never touches code. Owns KB_26; hands build work to engineering roles, regulatory verification to compliance-engineer, scope arbitration to cto-reviewer. Auto-routes via slug keywords (market, gtm, pricing, positioning, persona, icp, viability, pitch, prd) and /begin keyword suggestions. This reset was its first assignment.

7. What did NOT change

  • No code: zero edits in backend/ or frontend-nextjs/; audit baseline stayed exactly 402; no --baseline rewrite, no close-task.sh (nothing closed).
  • No new build scope: zero stages added; N-domain heads, energy, dynamic features, twin upgrades all stay at their ledgered stages.
  • No edits to frozen records: all prior PRDs, all prior ADRs, all prior research sections, the CTO remediation map — untouched.
  • Debts still owed (now scheduled): independent CTO #1 pass (G-031) and Stage 3 independent re-audit (G-001) — Stage 6 pre-requisites; proxy-trained brains (G-035) — pilot re-fit; reference pilot (G-043) — Stage 22.
  • The honest caveat: the product remains spec-deep/code-thin until Stage 6+ ship. This reset improved the map, not the territory — deliberately, and it says so.
