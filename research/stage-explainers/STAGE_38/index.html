The optimisation, precisely

minimise   Σ_t Σ_j (kw_j · h · ToU_price_t) · x[j,t]      # ToU energy cost of the shiftable loads
         + demand_charge · peak                          # demand charge on the day's aggregate peak
s.t.       Σ_t x[j,t] = required_slots[j]     ∀ j         # PRODUCTION FLOOR — every stage delivers its full output
           x[j,t] = 0     for t ∉ window[j]               # respect each load's allowed window
           peak ≥ base_t + Σ_j kw_j · x[j,t]  ∀ t         # peak dominates every slot's aggregate kW
           x[j,t] ∈ {0,1},  peak ≥ 0

The equality constraint is the honesty guarantee: shifting moves load in time, it never drops a stage's required run-hours. Solved deterministically by HiGHS (already installed — no new dependency).

Honesty (Rule 1a)

  • Real signals. Per-stage kW is the sim's real calibrated nominal_kw; the HVAC baseline is an explicitly labelled documented fraction.
  • Documented, labelled tariff. The ToU prices + demand charge are representative published-structure constants, not a real utility schedule — labelled everywhere. The optimiser is tariff-agnostic, so only the absolute $ numbers depend on it. A real pilot swaps in the customer's tariff + meter (G-035, buyer-blocked).
  • Deterministic A/B, honestly summarised. The MILP is deterministic, so the sweep is parametric (production intensity × window) — reported as mean/std/min/max, not a t-CI (which would misrepresent a non-random sample).
  • Hard Rule 3 intact. No actuator emitter in the facilities package (grep-verified + a test); the load-shift is routed through the validator; the sole emitter remains master.dispatch_order.
