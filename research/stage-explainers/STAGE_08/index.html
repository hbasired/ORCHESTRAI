1. What this stage built

Stage 8 deepens the self-healing loop's PREDICT step (KB_25 step 1) from an instantaneous failure-risk score into a learned world model that forecasts time-to-failure (TTF) — KB_25's own example is "LSTM predicts M fails in ~8 min." TTF is precisely the timing signal Stage 7's RL intervention lacked (it knew a machine was at-risk but not when it would fail). It also begins the CAUSALLY-REASON step (step 2) with a bounded, honest causal attribution v1: a counterfactual that separates a real machine fault from a plant-wide event that merely co-occurs.

TTF MAE 0.067 min — a 97.8% improvement over the naive baseline.

2. The measured win MEASURED

A real LSTM trained on seeded SimWorld crack rollouts (3,251 train / 852 val windows; no external dataset; labels are ground-truth from the sim's own crack schedule). Report: backend/training/evals/stage08/results.{json,md} + models/world_model_ttf.metrics.json.

4. Causal attribution v1 G-020 PARTIAL

A do-operator counterfactual over the known SimWorld structural causal model (KB_05): in that SCM a machine's intrinsic risk axes (rpm/torque/wear/temp-gap) are driven by its own crack proximity, not by plant-wide incidents. So:

  • Genuine wear fault and a co-occurring power_dip → stays machine_local (the do(remove power_dip) counterfactual leaves crack-proximity unchanged → still at-risk; the incident is ruled out as the cause).
  • Power-anomaly reading driven by an active power_dip → externally_influenced (do(remove power_dip) clears it → don't "fix" the machine).
  • Model flags risk but no structural rule fires → indeterminate (model-only signal).

This stops the coordinator from maintaining a healthy machine when a plant-wide event is the real driver, and confirms an intrinsic fault is genuine even when an unrelated incident co-occurs.

5. Honest scope & what is NOT built

  • NOT learned causal discovery — the SCM structure is known/documented, not learned from data.
  • NOT neuro-symbolic VERIFICATION (KB_25 step 3) — that remains PLANNED (G-020 stays open → Stage 17 / a research spike, as the gaps ledger flags).
  • Proxy/sim only (G-035) — the 0.067-min MAE is a clean-simulator number; real telemetry is noisier. Re-fit before any production claim.
  • Causal headroom is limited at current sim fidelity (external incidents barely perturb the AI4I risk axes), so the attribution is deliberately bounded — stated, not oversold.
  • Not actuator-wired; the Stage-17 functional-safety wrapper precedes any real-world use.
