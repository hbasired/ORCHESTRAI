1. What this stage built

Stage 9 delivers the Quality & Inspection vision capability (gap G-016) in two genuine, honest pieces:

  • De-mocked the vision model from a random-detection stub to real pretrained YOLOv8n inference — and removed a fabricating loop that had been feeding fake robot positions into the live state path.
  • Trained a real surface-defect classifier on the public NEU-CLS benchmark (6 steel-surface defect classes) — a genuine, measured model.

Audit baseline 396 → 383 — the first strict decrease since Stage 6.

Unlike Stages 7–8 (additive, flat baseline), this stage removed real grep-counted theatre, so it earns a genuine decrease with no --no-baseline-drop.

2. The de-mock — real YOLOv8n DE-MOCK

backend/ml/vision_model.py previously called _generate_mock_detections() — fabricating 15–25 random bounding boxes with random confidences whenever ultralytics/weights were absent — and video_processor.py ran a _mock_process_loop that pushed those fakes into the state manager. Both are removed. Now:

  • detect() / detect_batch() run real pretrained YOLOv8n (backend/yolov8n.pt, ultralytics 8.3.40) — verified to execute genuine inference.
  • When ultralytics/weights are absent, they raise ModelUnavailableError — never fabricate (mirrors failure_predictor / world_model).
  • Video processing is disabled honestly when OpenCV/source is unavailable — no fake robot positions ever reach the live state.

5. Honest scope & proxy caveats

  • PROXY domain (G-035): NEU-CLS is steel-surface defects — a proxy for this project's eventual warehouse/line imagery. The 88.2% does NOT transfer to deployment images; re-fit before any pilot.
  • Positional labels: the HF dataset carried no class names → class_0..5; the canonical NEU order is documented but the mapping is unverified.
  • YOLOv8n is COCO-pretrained, not warehouse-fine-tuned — genuine inference, but a warehouse fine-tune (Isaac Sim synthetic per KB_03) is a later refinement.
  • No Quality head-agent / no reject path: the full G-016 head-agent integration + real-time reject/divert are Stage 11+ (runtime) / Stage 17 (safety). This stage delivers the two real models + the de-mock only.
