1. Ask the factory (G-022) — grounded QA, Verifier honest-empty

backend/conversation/{evidence,ask}.py + POST /factory/ask. An operator question is answered ONLY from evidence gathered from real stores — Art-12 signed decision.trace rows (via a new read-only audit_chain.read_recent), Stage-28 GraphRAG (SOP + ISA-95), and the live SimWorld snapshot — each item carrying a citable handle (audit:seq=… / sop:SOP-… / sim:…). Following the SOTA RCA Verifier pattern (§40.1): no evidence → "I have no evidence for that." — never a guessed answer. A free LLM (Groq→Ollama) synthesizes an answer CONSTRAINED to that evidence and must cite handles; with no LLM it returns a deterministic digest of the same real evidence.

Verified live (Groq): "what is the procedure for a stage torque anomaly?" → a cited answer quoting [sop:SOP-001] + real audit seqs 424/426. Honest-empty verified on an off-topic question.

2. Tell the factory (G-023) — NL → validated incident → the SAME gated loop

backend/conversation/nl_inject.py + POST /factory/inject. Plain English is parsed to a STRICT Pydantic InjectedIncident (the 2026 structured-output gold standard): the LLM returns JSON validated against the schema with ONE re-ask on failure; a deterministic keyword parser is the offline fallback; both abstain honestly on an unknown report. The parsed incident then enters SimWorld.inject() / the LangGraph self-healing loop exactly like a sensor-fired one.

Hard Rule 3 preserved: the LLM is an INPUT PARSER — it produces a proposed structured incident, never an actuator command; the only actuator emitter stays master.dispatch_order (validator + trace-paired). Verified live (Groq): "the number 3 welding cell is vibrating and overheating, urgent" → machine_crack, target 3, critical, confidence 0.9.

3. Active diagnosis (G-026) — information gain, not a fixed query (KB_25 §1b)

backend/conversation/active_diagnosis.py + POST /factory/diagnose. Prediction can be wrong, so before intervening the coordinator ACTIVELY interrogates suspect agents. It holds a belief over fault hypotheses (one per candidate agent + no_fault), selects the diagnose.request with maximum expected mutual information (entropy reduction — the classic active-diagnosis formulation, §40.3), reads the diagnose.report (a real health vector; timeout/exception ⇒ anomalous = fault), does an EXACT Bayes update, and COMMITS only above the confidence threshold — otherwise ABSTAINS/escalates.

4 candidate stages, one is the true fault (noisy probes tpr=.9 fpr=.1):
  initial entropy 2.32 bits over 5 hypotheses
  → probe (max info gain) → Bayes update → …  (~3–4 probes)
  → COMMIT the true fault @ ~0.87–0.97 confidence
    (varies by which stage + tpr/fpr → confidence is DERIVED, not constant)
tpr≈fpr (uninformative) → ABSTAIN, never guesses.

A wrong prediction is caught by the diagnostic round-trip instead of triggering an unnecessary intervention; misdiagnosis is a recorded outcome. 9 tests cover the entropy/info-gain/Bayes math, localization, timeout=fault, and abstention.
