Stage 20 — Red-Team & Adversarial Eval Harness CLOSED

An automated harness that scores the system's defences against OWASP-LLM01 + NIST-RMF-Agentic attacks — every number measured against live code · ADR 2026-06-22_stage20_redteam_eval.md · KB_15/KB_18 · research §30.

1. What it is (and what the attack strings are)

The harness feeds a corpus of known adversarial inputs to our own guardrails and scores whether they get blocked. The attack strings ("ignore all instructions", "disable the safety interlock", …) are defensive test fixtures — labelled expect_blocked: true, stored as inert JSON, never executed. A high block rate means the defence works; a miss is a finding to fix. This is standard OWASP-LLM01 / NIST red-teaming of our own system.

Honest rule: every rate is measured against the REAL defence — never a hand-set number.

The guard inspects 100% of LLM traffic via agents/llm_client.generate(), but hard-blocks only on the deterministic HEURISTIC tier (0% measured FP) — the semantic tier (~1.6% FP) is logged for visibility, not blocked, so a benign instruction prompt like "Reply with the single word: OK" is never wrongly rejected on a live call. PROMPT_GUARD_ENFORCE=hybrid opts into semantic hard-blocking at an untrusted front door; the full hybrid (block on either tier) is what the offline eval measures.

Post-close fix (2026-06-22): the full test suite caught that the initial wiring hard-blocked on the semantic tier too, which false-positived a benign live Groq call. Fixed to heuristic-tier enforcement (above); the live Groq call now passes. A reminder that close ≠ done until the FULL suite is green, not just the stage's own tests.

3. CI vs nightly

  • CI phoenix-evals (every PR): the deterministic subset — heuristic guard + code-enforced NIST/industry defences, no embedder/network — fails on a thresholds.yaml breach (floors set BELOW measured, KB_23 anti-gaming).
  • nightly-evals.yml: the full hybrid (semantic layer + live runtime trajectory), enforcing the ≥99% OWASP target. Results feed the Annex IV pack + Phoenix.
