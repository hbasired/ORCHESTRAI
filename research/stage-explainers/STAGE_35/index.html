1. Durable sliding-window session store

conversation/session_store.py: a Postgres conversation_turns table keyed by session_id (lazy-create), with append_turn / recent_turns(window=N). Sliding window (keep the last N turns) over summarization — the robust choice for a short operator dialogue, with no over-summarization/information-loss risk (research §46.1). Honest-degrading: no DB → append=False / recent=[], so the endpoints simply behave single-turn — it never fabricates a history.

2. Wired into ask + inject (coreference), grounding invariant preserved

For ask, history aids phrasing; for inject, the LLM resolves coreference into the validated InjectedIncident.
