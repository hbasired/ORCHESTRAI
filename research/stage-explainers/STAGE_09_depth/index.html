1. Why this deepening

The v1 Stage-9 classifier was a toy 3-conv grayscale CNN at 64×64 → 88.2% on the real NEU-CLS benchmark. NEU-CLS deep-model SOTA is ~99%. 88.2%, where transfer learning reaches ~99% free/local on CPU, is the shallow shortfall Hard Rule 11a forbids — so it is re-done deep.

88.2% → 99.3% test accuracy via pretrained ResNet18 transfer learning.

2. What was built TEST ACC 0.993

backend/training/stage_09_defect/train_transfer.py: a pretrained ImageNet ResNet18, final fc → 6 classes, with layer4 + fc fine-tuned (backbone frozen — ~13 s/epoch on CPU), on real NEU-CLS at RGB 128×128 (ImageNet-normalised, grayscale replicated to 3 channels), light H/V-flip augmentation, cosine schedule, best-val checkpoint selection.

3. Honest, leakage-free

dataset_tl.load_defect_data_rgb reuses the exact same stratified split (seed 9, 20% test) as the v1 grayscale loader, so the held-out test images are identical and the transfer model never trains on them — the +11.1 pt gain is a real held-out improvement, and the existing test_defect_classifier_beats_baseline_on_real_holdout stays meaningful.

The inference glue backend/ml/defect_classifier.py auto-detects arch from the checkpoint (resnet18 → torchvision backbone + RGB/ImageNet preprocessing, accepts grayscale/RGB/PIL of any size; old tiny-CNN checkpoints still load).
