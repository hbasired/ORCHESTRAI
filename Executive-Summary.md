## ⚠️ COMMON PITFALLS TO AVOID

### 1. **Scope Creep**
- ❌ Don't add "nice-to-have" features
- ✅ Focus on MVP: robot tracking + stage monitoring + decisions

### 2. **Perfection Paralysis**
- ❌ Don't spend 2 weeks optimizing one model
- ✅ Get it working first, optimize later

### 3. **No Testing**
- ❌ Don't deploy without tests
- ✅ Write tests as you code (TDD if possible)

### 4. **Unclear Metrics**
- ❌ Don't build without knowing what success looks like
- ✅ Define KPIs on Day 1 (efficiency %, latency, uptime)

### 5. **No Documentation**
- ❌ Don't assume you'll remember how it works
- ✅ Document as you code (README, code comments, API docs)

### 6. **Poor DevOps**
- ❌ Don't deploy manually, don't use hardcoded secrets
- ✅ Use CI/CD, environment variables, infrastructure-as-code

### 7. **Ignoring Performance**
- ❌ Don't ignore latency or memory usage
- ✅ Profile early, optimize bottlenecks
